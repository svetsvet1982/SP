### 시리즈 관통 서사
1. **1부** — 헬레나는 데이터와 현장으로 문제를 푸는 유능한 컨설턴트. 그러나 스승 호드리구가 고객사(Moretti)의 대량 해고 보고서를 밀어붙이자 사표를 던진다. 창업주가 그녀를 CEO로 영입.
2. **2부** — 헬레나(CEO)와 치아구(CFO)가 망해가는 가족 제조기업을 살린다. 그러나 회사가 사모펀드에 매각되며 둘은 물러난다. 매각 과정에서 "누군가 숫자를 미리 알고 있었다"는 의문이 남는다.
3. **3부** — 둘은 독립해 경영감사 회사 *Lupa*를 차린다. 병원·축구클럽·협동조합·핀테크를 감사하며 이름을 얻고, 마지막에 옛 회사 VLA와 사모펀드 Ipê Capital의 유착(1부·2부의 배후)을 밝혀낸다.
4. **4부** — 스캔들 이후 "숫자를 두려워하지 않는 사람"으로 유명해진 헬레나가 지지율 4%의 시장 후보 캠프에 영입된다. 상대 진영 전략가는 1부의 라이벌 카이우. 결선투표까지 가는 선거전 끝에, 헬레나는 권력 대신 다시 컨설턴트의 자리로 돌아간다.

## 4. 회차 공통 형식 (120턴)

| 구간 | 턴 | 기능 |
|---|---|---|
| 도입 | 1~15 | 일상 장면 · 인물 관계 · 이번 화 과제 제시 |
| 장면1 | 16~50 | 문제 탐색 (데이터·현장·인터뷰) |
| 장면2 | 51~80 | 갈등 심화 (고객 저항·내부 대립·반전 단서) |
| 절정·전환 | 81~105 | 해법 제시 / 설득 / 결정 |
| 마무리 | 106~120 | 여운 · 다음 화 훅 |

### 대본 머리 정보(표기 전용, 낭독하지 않음)
```
- 부/화 · 서사 기능
- 배경 (장소·시간)
- 등장인물
- 경영 개념 (이번 화에서 다루는 프레임워크)
- 난이도 · 턴 수 (구간 배분)
- 규칙: 지문 없음, 1턴 25단어 이내, 단문 나열 지양
- 복선 설치 / 회수
```

### 학습 설계 원칙
- 매 화 **경영 개념 1개**를 대화 속에서 자연스럽게 설명한다 (예: MECE, 80/20, 현금흐름, BATNA, COSO, 결선투표 전략).
- 매 화 **핵심 표현 3개**를 반복 노출한다 (도입 1회 · 장면 1회 · 마무리 1회).
- 존댓말 체계(*o senhor / a senhora* ↔ *você*)를 인물 관계 변화의 장치로 쓴다.
- 부가 올라갈수록 문법·어휘 수준 상승: 1부 직설법 중심 → 2부 접속법·조건법 → 3부 수동태·간접화법·법률 어휘 → 4부 수사법·논증·토론 화법.
