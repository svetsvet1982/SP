# Faria Lima — 1부 「O Diagnóstico」 (진단)

> 민간기업 컨설팅 · 14화 · 난이도 B1 · 무대: VLA 사무실(Faria Lima), 고객사 현장

## 1부 개요
- **주제**: 문제를 정확히 정의하는 것이 해법의 절반이다.
- **구조**: 4개 프로젝트(케이스) + 1부 결말
  - 케이스 A (1~4화) 슈퍼마켓 체인 *Rede Bom Preço* — 수익성 하락 진단
  - 케이스 B (5~7화) Bom Retiro 의류 도매상 *Confecções Kim* — 디지털 전환과 가업 승계
  - 케이스 C (8~10화) 사모펀드 *Ipê Capital*의 물류사 *TransVale* 인수 실사
  - 케이스 D (11~14화) 제조기업 *Indústria Moretti* — 원가절감 vs 대량해고
- **인물 아크**: 헬레나는 "고객이 원하는 답"과 "고객에게 필요한 답" 사이에서 점점 후자를 택하고, 결국 스승 호드리구와 결별한다.
- **1부 엔딩**: 헬레나 퇴사 → Seu Ângelo가 CEO 제안 → 치아구가 CFO로 동행. 비아는 VLA 잔류.

## 케이스 A — Rede Bom Preço (1~4화)

### 1화 「Primeiro dia na Faria Lima」 (파리아 리마의 첫날)
- **서사 기능**: 시리즈 도입 · 인물 소개 · 케이스 A 수주
- **배경**: VLA 사무실 18층, 월요일 오전 8시 → 오후 회의실
- **등장**: Helena, Thiago, Bia, Rodrigo, Caio, Dona Zuleica, Sr. Wagner Rocha(Bom Preço CEO)
- **경영 개념**: 컨설팅 회사 구조(파트너–매니저–애널리스트), 제안(proposta)
- **전개**
  - 도입: 비아의 첫 출근. 출입증이 안 돼 로비에서 헤맴. 조이레이카가 구해 줌.
  - 장면1: 호드리구가 팀 배정. 헬레나 팀에 비아·치아구. 카이우는 "신입은 짐"이라고 비꼼.
  - 장면2: Bom Preço CEO 와그너가 방문, "매출은 느는데 이익이 줄어요." 카이우 팀과 경쟁 제안.
  - 절정: 헬레나가 첫 질문 「Qual é o problema de verdade?」로 와그너의 마음을 얻음. 수주.
  - 마무리: 호드리구 "30일 안에 결과 못 내면 이 계정은 카이우 거야."
- **핵심 표현**: *Seja bem-vinda.* / *Qual é o problema de verdade?* / *Café primeiro, crise depois.*
- **복선**: 호드리구와 Ipê Capital 파트너의 통화(내용 불명) → 3부 11화

### 2화 「A árvore de problemas」 (문제 나무)
- **서사 기능**: 케이스 A 분석 착수
- **배경**: VLA 작업실(war room), 화이트보드
- **등장**: Helena, Thiago, Bia, Dona Zuleica
- **경영 개념**: 이슈 트리(issue tree), MECE, 가설 기반 접근
- **전개**
  - 도입: 화이트보드 쟁탈전. 치아구는 엑셀부터, 헬레나는 질문부터.
  - 장면1: 이익 = 매출 − 비용 → 가지 쪼개기. 비아가 "겹치면 안 된다"를 처음 배움.
  - 장면2: 가설 3개 수립(가격·비용·손실). 치아구와 헬레나의 우선순위 논쟁.
  - 절정: 비아가 "손실(perdas)이 빠졌어요"라고 지적. 새 가지 추가.
  - 마무리: 내일 Zona Leste 매장 현장 방문 결정.
- **핵심 표현**: *Vamos quebrar o problema.* / *Isso se sobrepõe.* / *Mostra o número.*
- **복선**: 비아의 첫 "quebrada" 말버릇

### 3화 「Os números não mentem, as pessoas sim」 (숫자는 거짓말을 안 한다, 사람이 할 뿐)
- **서사 기능**: 현장 조사 · 저항 세력 등장
- **배경**: Itaquera의 Bom Preço 매장, 창고와 계산대
- **등장**: Helena, Bia, Thiago, Sérgio Antunes(COO), Dona Rose(매장 관리자), 창고 직원
- **경영 개념**: 파레토 법칙(80/20), 현장 인터뷰 기법
- **전개**
  - 도입: 이른 아침 매장. COO 세르지우는 노골적으로 비협조.
  - 장면1: 비아가 창고 직원·계산원과 대화하며 폐기·도난 실태 파악.
  - 장면2: 치아구의 데이터: 손실의 80%가 신선식품 20% 품목에서 발생.
  - 절정: 세르지우의 보고 수치와 실제 수치가 다름을 발견.
  - 마무리: 헬레나 "고발이 목적이 아니에요. 이유를 알아야 해요."
- **핵심 표현**: *Os dados batem?* / *Me conta como funciona aqui.* / *Oitenta por cento vem de vinte.*
- **복선**: 세르지우의 "윗선 압박" 고백 → 4화 설득 포인트

### 4화 「A apresentação das oito」 (여덟 시 프레젠테이션)
- **서사 기능**: 케이스 A 완결
- **배경**: Bom Preço 본사 이사회실, 아침 8시
- **등장**: Helena, Thiago, Bia, Caio, Wagner, Sérgio, Rodrigo
- **경영 개념**: 피라미드 원칙(결론 먼저), 스토리라인, 이해관계자 설득
- **전개**
  - 도입: 전날 밤, 카이우가 "도와준다"며 슬라이드 파일을 건드림.
  - 장면1: 발표 직전 숫자 오류 발견. 치아구가 15분 만에 수정.
  - 장면2: 세르지우가 공개적으로 반박. 헬레나는 그를 비난하지 않고 "구조의 문제"로 재정의.
  - 절정: 세르지우가 해법의 책임자가 되겠다고 나섬. 와그너 승인.
  - 마무리: 호드리구 "잘했어. 하지만 다음엔 고객을 이렇게 오래 기다리게 하지 마."
- **핵심 표현**: *Começando pela conclusão...* / *Não é culpa de uma pessoa, é do processo.* / *Posso contar com o senhor?*
- **복선**: 카이우의 파일 조작 의심 → 13화
