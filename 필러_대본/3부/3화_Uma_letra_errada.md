- **통관 경과(3부 4화로 이어짐)**: 화요일 새벽 3시(서울 오후 3시) 오 과장 사과 → 특송을 두바이 대신 **프랑크푸르트 경유(하루 단축, 600달러, 한빛 부담)** → 새벽 5시 반 소피아가 전자본에서 **두 번째 오타 「BERTOLIN MED TECH」(i 누락) 발견** → 박 부장이 특송 멈춤, 오 과장과 「나란히」 재작성, 기사 40분 대기(추가 요금 오 과장 부담) → 오전 9시 오타비우: 한국 전자 서명 불인정 + 「Bertolin」도 이미 발견, 「먼저 찾는 사람은 기억한다, 목요일에 제일 먼저 검토」 → 수요일 밤 10시 과룰류스 도착, 켈리가 차로 운반(「원본은 품에 안겨서 잔다」) → 목요일 7시 원본 확인, 세관은 ANVISA 판단을 따름 → **정정 승인**(보관료 나흘 2만 헤알).
- **소피아의 「체면 지키기」 세 규칙(이후 화에서 활용)**: ① 탓하는 대신 도움을 청한다 ② 상대가 자기 빚을 갚게 해 준다(비용 부담 제안을 받아들인다) ③ 실수 뒤엔 상대가 잘한 진짜 일을 하나 떠올려 준다 · 「겁은 사람을 숨게 하고, 자존심은 고치게 한다」.
