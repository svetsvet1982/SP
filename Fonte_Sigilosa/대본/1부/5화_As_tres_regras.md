## 제작 메모 (낭독하지 않음)
- 핵심 어휘: disfarce·disfarçado — 위장·위장한 / infiltração — 잠입 / regra — 규칙 / crime·cúmplice·testemunha — 범죄·공범·목격자 / interesse público — 공익 / dano — 침해·피해 / saída — 출구 / palavra de código — 암호 / currículo — 이력서 / vaga — 일자리·채용 자리 / referência — 경력 확인·추천인 / decorar — 외우다
- 문법 포인트 1: 명령법 — "Fecha a porta", "Anota, Digo", "Manda pro e-mail"(구어 tu형) vs "Venha amanhã", "Não se atrase"(격식 você형·접속법 형태). 같은 명령도 관계에 따라 형태가 달라진다.
- 문법 포인트 2: se + 접속법 미래의 관용 — "Se uma falhar", "Se acontecer alguma coisa", "E se a gente não fizer nada"(B1 단계 노출용, 패턴으로 익히기).
- 문법 포인트 3: 강조 구문 "Quem paga a conta sou eu", "Quem tá sendo roubado é a gente" — quem … é/sou 분열문.
